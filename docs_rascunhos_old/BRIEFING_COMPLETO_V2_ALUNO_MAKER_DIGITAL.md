# 📌 PILAR 1 — VISÃO ESTRATÉGICA

## Identidade do Projeto
- **Nome:** Aluno Maker Digital
- **Slogan:** "Criar é o melhor caminho." **Não gostei desse slogan e necessito de um mais impactante e curto**
- **Domínio:** alunomakerdigital.com.br
- **Hospedagem:** Hostinger Business (Node.js + MySQL + CDN)
- **Ativo desde:** 2018
- **Localização:** Recanto das Emas — Brasília/DF
- **Responsável:** Professor Francenylson

## Missão
Transformar alunos da Educação Básica em criadores ativos de tecnologia,
tirando-os da posição de consumidores passivos e colocando-os como
protagonistas do próprio futuro através da robótica, programação e IA.

## Visão
Ser a maior referência nacional em robótica educacional para escolas públicas,
reconhecida pela transformação real e permanente na vida dos alunos.

## Valores
- **Protagonismo** — o aluno é o criador, não o espectador
- **Permanência** — conhecimento que dura para sempre
- **Inclusão** — tecnologia para quem mais precisa
- **Inovação** — sempre na fronteira do que é possível
- **Impacto social** — transformar comunidades vulneráveis

## Contexto Social (CRÍTICO)
O projeto atende alunos em situação de alta vulnerabilidade social no
Recanto das Emas. Tráfico e violência fazem parte do cotidiano.
Toda comunicação deve transmitir **esperança, protagonismo e transformação.**
NUNCA usar linguagem que possa ter conotação negativa para esse público.

## Público-alvo

### Público Primário (quem usa)
- Alunos do 5º ano do EF ao 3º ano do EM
- Faixa etária: 10 a 18 anos
- Perfil: jovens em vulnerabilidade social, curiosos, energia alta
- Dor: falta de perspectiva e de conexão com o futuro
- Alunos com TEA (autistas) em turmas inclusivas
- Alunos cadeirantes (próxima etapa de ampliação do projeto será atender esses alunos) 

### Público Secundário (quem compra)
- **Professores** de outras escolas querendo replicar o projeto
- **Diretores e coordenadores** buscando inovação pedagógica
- **Pais** que querem o melhor para os filhos
- **Secretarias de Educação** buscando projetos de impacto
- **Empresas** para patrocínio e responsabilidade social

### Público Terciário (parceiros)
- Fabricantes de componentes eletrônicos
- Universidades e institutos de pesquisa
- ONGs e fundações de impacto social
- Imprensa e mídia educacional

## Objetivos Estratégicos do Site

### Objetivo Principal
Converter visitantes em leads qualificados que agendem visitas,
comprem cursos ou contratem mentorias.

### Jornada do Visitante Ideal
```
Descobre o projeto (redes sociais / Google)
        ↓
Acessa o site e SE IMPRESSIONA com os projetos
        ↓
Assiste a vídeos dos robôs funcionando
        ↓
Lê sobre a transformação dos alunos
        ↓
Agenda uma visita gratuita (isca principal)
        ↓
Visita presencial → vê os robôs ao vivo
        ↓
Confia → Compra curso / mentoria / consultoria
        ↓
Vira embaixador do projeto
```

# 🏗️ PILAR 3 — ARQUITETURA TÉCNICA

## Stack Tecnológico

### Frontend (Site público)
```
HTML5 semântico
CSS3 com variáveis customizadas (CSS Custom Properties)
JavaScript ES6+ vanilla (sem framework — mais leve e rápido)
Intersection Observer API (animações de entrada)
Swiper.js (sliders e carrosséis)
GLightbox (galeria com lightbox)
Google Fonts (Orbitron + Inter)
Font Awesome 6 (ícones)
```

### Backend — Painel Admin (Fase 2)
```
Node.js + Express.js (roda nas 5 apps da Hostinger)
MySQL (banco de dados — incluso na Hostinger)
JWT (autenticação segura)
Multer (upload de fotos e vídeos)
Nodemailer (envio de e-mails do formulário)
Claude API (gerador de conteúdo com IA)
```

### Integrações Externas
```
Instagram Graph API (publicação automática)
TikTok Content Posting API (publicação)
WhatsApp Business (botão flutuante)
Google Analytics 4 (métricas)
Google Maps API (mapa de localização)
Mercado Pago API (pagamentos — fase 2)
Mailchimp ou Brevo (newsletter)
```
